# AHR Solutions

Sistema web de gerenciamento de chamados desenvolvido para organizar solicitações de suporte, acompanhar atendimentos e facilitar a comunicação entre usuários e equipes responsáveis.

O projeto foi desenvolvido com foco em uma estrutura simples, organizada e preparada para integração entre frontend, backend e banco de dados.

## Sobre o projeto

O AHR Solutions é uma aplicação de Help Desk que permite o gerenciamento completo de chamados, desde a abertura da solicitação até sua resolução.

O sistema busca centralizar as informações de suporte em um único ambiente, permitindo maior organização e controle dos atendimentos.

## Funcionalidades

- Autenticação de usuários
- Abertura de novos chamados
- Listagem de chamados
- Visualização detalhada de chamados
- Atualização de status
- Comentários e histórico de atendimento
- Atribuição de chamados para equipes
- Fila de atendimento
- Filtros e busca
- Dashboard com informações gerais
- Administração de usuários
- Gerenciamento de equipes
- Gerenciamento de categorias
